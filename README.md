YouCast (headless fork)
=======================

> [!NOTE]
> This is a fork of [i3arnon/YouCast](https://github.com/i3arnon/YouCast), ported to a headless
> .NET 10 service for Linux. The Windows GUI is removed. It is run and tested on a home server
> with Apple Podcasts on iOS; other podcast apps and Windows are untested.

**Requirements:** .NET 10 (ASP.NET Core runtime), `ffmpeg` for video feeds, and your own
YouTube Data API key. YouTube blocks most datacenter IP addresses, so run it from a home connection.

Changes from the original:
- Headless ASP.NET Core service configured by `/etc/youcast.conf`; RPM spec and an EL10 container file in `packaging/`
- Audio feeds serve the original-language AAC track (not a dubbed one)
- Video feeds (360p/720p): video and audio downloaded separately and joined with ffmpeg, kept in a disk cache with HTTP range support
- Live streams, scheduled broadcasts and videos YouTube is still processing are left out of the feed until they can be played
- Feed lists are cached and updated incrementally (about one API call per feed refresh), and the last saved feed is served when YouTube cannot be reached
- Channels can be given as `@handle`, channel id or old username
- Uses a YoutubeExplode fork (submodule `third_party/YoutubeExplode`) that loads stream lists faster

## About YouCast

*The rest of this README comes from the original project, updated for this fork where needed (Usage and the API key steps).*

YouCast allows you to subscribe to channels and playlists on YouTube as video and audio podcasts in any standard podcast app (e.g. Overcast, iTunes, BeyondPod, etc.).

## Features
 - Subscribe to any channel's public video uploads.
 - Subscribe to any public playlist on YouTube.
 - Get audio-only feeds (for faster downloads).
 - Sort the videos by popularity (awesome for huge channels, like TED Talks)
 - Run YouCast at home and access it from everywhere on the internet, not just your home network.
 - Limit the amount of videos in any feed (helps with users with thousands of videos).
 - Use YouCast from any device in your network: iPhone, Android, Tablet. (Just open the incoming port 22703 on your firewall and paste the URL in your podcast app)

## Usage
YouCast runs as a headless service (systemd on Linux, Windows service planned). See [packaging/INSTALL.md](packaging/INSTALL.md).
Configure it in `/etc/youcast.conf` (see [packaging/youcast.conf.example](packaging/youcast.conf.example)).

Podcast URLs are built by hand:

- Channel: `http://HOST:22703/FeedService/GetUserFeed?userId=CHANNEL_ID_OR_NAME&encoding=Audio&maxLength=0&isPopular=false`
  `CHANNEL_ID_OR_NAME` is a channel id (`UC…`), an `@handle` (write `%40handle` in the URL) or an old username.
- Playlist: `http://HOST:22703/FeedService/GetPlaylistFeed?playlistId=PLAYLIST_ID&encoding=MP4_720p&maxLength=0&isPopular=false`

`encoding` is `Audio` (MP4/AAC audio) or `MP4_360p` / `MP4_720p` (H.264 video + AAC, joined on the server with ffmpeg and cached; see [packaging/INSTALL.md](packaging/INSTALL.md)). Without ffmpeg, every value serves audio. `maxLength=0` means unlimited.

### Setting your own API Key
Google restricts the amount of requests you can make per day with each API key. In order to circumvent this limit, you can set your own API key.

1. Go to the [Google Developers Console](https://console.developers.google.com/).
2. Make a new application. It can take a couple of minutes for the application to be generated by Google.
3. Assign the Youtube Data API v3 to the application.
4. Generate an API key for Youtube Data API v3.
5. Put the key in `ApiKey` (and optionally `ApplicationName`) in `/etc/youcast.conf`, then `systemctl restart youcast`.
